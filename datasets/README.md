# 数据集说明（Shin2017 EEG-fNIRS 运动想象数据集）

本目录统一存放项目全部数据：`raw/` 保存原始数据集，`processed/` 保存预处理脚本生成的张量缓存。

## 1. 数据集来源

Shin 等人 2017 年发布的**同步 EEG 与 fNIRS 运动想象公开数据集**，采集受试者执行左手 / 右手运动想象任务时的脑电与近红外信号。

## 2. 原始数据 `raw/`

```
raw/
├── EEG/      # subject 01 ~ subject 29（共 29 名被试）
└── fNIRS/    # subject 01 ~ subject 29（共 29 名被试）
```

| 项目 | 内容 |
| --- | --- |
| 被试数量 | 29 名（subject 01–29） |
| 任务类别 | 左手运动想象（LMI）、右手运动想象（RMI） |
| EEG 通道 | 30 通道 |
| fNIRS 通道 | 36 通道（含 HbO 与 HbR 两种血氧信号） |
| 切片后总试次 | 1740（LMI 870 / RMI 870，类别完全均衡） |

> 注意：`raw/` 目录体积约 13.4GB，已在 `.gitignore` 中排除，不纳入版本控制。

## 3. 预处理张量 `processed/`

由 `data/preprocess_shin.py`、`data/topology_builder.py` 生成，为切片与对齐后的张量缓存：

| 文件名 | 形状 | 说明 |
| --- | --- | --- |
| `eeg_epochs.pt` | [1740, 30, 4000] | EEG 试次张量（试次 × 通道 × 时间点） |
| `fnirs_hbo_epochs.pt` | [1740, 36, 256] | 氧合血红蛋白 HbO 试次张量 |
| `fnirs_hbr_epochs.pt` | [1740, 36, 256] | 脱氧血红蛋白 HbR 试次张量 |
| `topo_correlations.pt` | — | 空间拓扑与通道相关性矩阵 |

- 标签：1740 个试次对应 LMI/RMI 两类，与上述张量按试次维度严格对齐。
- 该目录下的 `.pt` 为生成产物，已在 `.gitignore` 中排除（仅保留 `.gitkeep` 占位）；删除后可用预处理脚本重新生成。

## 4. 数据使用约定

1. 不直接修改 `raw/` 中的任何原始文件，所有清洗与变换在 `processed/` 产出。
2. 预处理、Dataset、拓扑构建逻辑分别放在 `data/` 目录下的对应脚本中，数据目录本身只存放数据。
